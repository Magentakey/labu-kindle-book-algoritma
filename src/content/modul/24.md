@@ pendahuluan | PENDAHULUAN | 1. Menyelesaikan yang Terdekat Lebih Dulu

Bellman-Ford (Modul 23) merelaksasi semua busur berulang kali tanpa memedulikan urutan, sehingga running time-nya $\Theta(V E)$. Jika semua bobot **tidak negatif**, kita bisa jauh lebih cerdas. Pikirkan: simpul yang saat ini memiliki estimasi jarak terkecil tidak mungkin dicapai lebih murah lewat simpul lain, karena setiap jalan memutar hanya menambah bobot (atau tidak mengubahnya). Jadi jaraknya sudah **final**, dan kita cukup merelaksasi busur keluar dari simpul itu **sekali saja**.

Inilah gagasan **algoritma Dijkstra** (Dijkstra, 1959). Ia adalah algoritma Greedy (Modul 13): di setiap langkah, ia "mengunci" simpul dengan jarak sementara terkecil. Hasilnya sama dengan Bellman-Ford, tetapi jauh lebih cepat. Syaratnya tegas: tidak boleh ada bobot busur yang negatif.

Modul ini membahas pseudocode Dijkstra dari bahan kuliah, menelusurinya pada graf lima simpul, menjelaskan kebenarannya, memberi contoh ketika syarat bobot nonnegatif dilanggar, dan menganalisis running time-nya.

| Langkah | Penjelasan |
| --- | --- |
| 1 | Inisialisasi: setiap simpul $v.d = \infty$ dan $v.\pi = $ NIL; $s.d = 0$. |
| 2 | $S$ dikosongkan. $S$ berisi simpul-simpul yang jarak terpendeknya dari $s$ sudah final. |

### 3.2 Implementasi Python

Dengan `heapq`, setiap kali $v.d$ turun, pasangan baru $(v.d, v)$ dimasukkan ke heap; entri lama untuk simpul yang sudah di $S$ diabaikan. Teknik ini setara dengan DECREASE-KEY.

```python
import heapq
INF = float("inf")

def dijkstra(G, s):
    d = {v: INF for v in G}; pi = {v: None for v in G}; d[s] = 0
    S, Q = [], [(0, s)]
    while Q:
        du, u = heapq.heappop(Q)                 # EXTRACT-MIN
        if u in S:
            continue                             # entri usang
        S.append(u)
        for v, w in G[u]:                        # RELAX setiap busur keluar
            if d[v] > du + w:
                d[v], pi[v] = du + w, u
                heapq.heappush(Q, (d[v], v))
    return d, pi, S

def lintasan(pi, v):
    return lintasan(pi, pi[v]) + " -> " + v if pi[v] else v

G = {"s": [("t", 10), ("y", 5)], "t": [("x", 1), ("y", 2)], "x": [("z", 4)],
     "y": [("x", 9), ("z", 2), ("t", 3)], "z": [("s", 7), ("x", 6)]}
d, pi, S = dijkstra(G, "s")
print("urutan extract:", S)
for v in "txyz":
    print(v, d[v], lintasan(pi, v))
```

```text

t 8 s -> y -> t
x 9 s -> y -> t -> x
y 5 s -> y
z 7 s -> y -> z
```

@@ analisis | PEMBAHASAN INTI | 4. Mengapa Dijkstra Benar, dan Kapan Gagal

### 4.1 Gagasan kebenaran

Klaim kuncinya (Cormen dkk., 2009, Teorema 24.6): ketika simpul $u$ di-extract dan dimasukkan ke $S$, berlaku $u.d = \delta(s, u)$. Gagasan buktinya: misalkan ada lintasan lain dari $s$ ke $u$ yang lebih murah. Lintasan itu harus keluar dari $S$ pada suatu busur $(x, y)$ dengan $x \in S$ dan $y \notin S$. Karena $x$ sudah final dan busurnya sudah direlaksasi, $y.d = \delta(s, y)$. Karena semua bobot **nonnegatif**, bagian lintasan dari $y$ ke $u$ tidak mengurangi bobot, sehingga $\delta(s, y) \le$ bobot lintasan itu $< u.d$. Akibatnya $y.d < u.d$, padahal $u$ dipilih karena nilainya terkecil di $Q$. Kontradiksi. Jadi $u.d$ memang sudah jarak terpendek.

Langkah "karena semua bobot nonnegatif" adalah titik tempat syarat Dijkstra benar-benar dibutuhkan.

### 4.2 Contoh kegagalan dengan bobot negatif

{{callout:benar|Contoh penyangkal}}
Graf: $(s, a) = 2$, $(s, b) = 3$, $(b, a) = -2$, $(a, c) = 1$. Jarak sebenarnya: $\delta(s, a) = 3 + (-2) = 1$ dan $\delta(s, c) = 1 + 1 = 2$.

Dijkstra: extract $s$ (a = 2, b = 3) → extract $a$ (nilai terkecil 2), lalu RELAX $(a, c)$ memberi $c = 3$ → extract $b$, RELAX $(b, a)$ menurunkan $a$ menjadi 1, tetapi $a$ sudah di $S$ dan busur keluarnya tidak pernah direlaksasi lagi → extract $c$ dengan $c.d = 3$. Hasil akhir $c.d = 3$, padahal $\delta(s, c) = 2$. **Salah.** Untuk graf seperti ini harus memakai Bellman-Ford.
{{/callout}}

```python
INF = float("inf")
G = {"s": [("a", 2), ("b", 3)], "a": [("c", 1)], "b": [("a", -2)], "c": []}

def dijkstra_buku(G, s):                  # mengikuti pseudocode: RELAX tanpa syarat
    d = {v: INF for v in G}; d[s] = 0; Q = set(G)
    while Q:
        u = min(sorted(Q), key=lambda v: d[v]); Q.remove(u)
        for v, w in G[u]:
            if d[v] > d[u] + w:
                d[v] = d[u] + w
    return d

def bellman_ford(G, s):
    d = {v: INF for v in G}; d[s] = 0
    for _ in range(len(G) - 1):
        for u in G:
            for v, w in G[u]:
                if d[v] > d[u] + w:
                    d[v] = d[u] + w
    return d

print("Dijkstra    :", dijkstra_buku(G, "s"))
print("Bellman-Ford:", bellman_ford(G, "s"))
```

Keluaran program:

```text
Dijkstra    : {'s': 0, 'a': 1, 'b': 3, 'c': 3}
Bellman-Ford: {'s': 0, 'a': 1, 'b': 3, 'c': 2}
```

@@ makna | ANALISIS DAN HUBUNGAN KONSEP | 5. Running Time dan Perbandingan

### 5.1 Running time

Dijkstra melakukan $\lvert V \rvert$ kali EXTRACT-MIN dan setiap busur direlaksasi tepat sekali (karena adjacency-list setiap simpul hanya diproses saat simpul itu di-extract), sehingga ada paling banyak $\lvert E \rvert$ penurunan nilai (DECREASE-KEY). Running time-nya bergantung pada implementasi $Q$ (Cormen dkk., 2009, Bab 24.3):

| Implementasi $Q$ | EXTRACT-MIN | DECREASE-KEY | Total |
| --- | --- | --- | --- |
| Array biasa (indeks simpul) | $O(V)$, sebanyak $\lvert V \rvert$ kali | $O(1)$, sebanyak $\lvert E \rvert$ kali | $O(V^2 + E) = O(V^2)$ |
| Binary min-heap | $O(\lg V)$ | $O(\lg V)$ | $O((V + E) \lg V)$ |
| Fibonacci heap | $O(\lg V)$ amortized | $O(1)$ amortized | $O(V \lg V + E)$ |

*Tabel 5. Running time Dijkstra.*

Untuk graf jarang (misalnya jaringan jalan), binary heap jauh lebih cepat daripada array. Untuk graf sangat padat, array $O(V^2)$ sudah sangat baik. Versi Fibonacci heap berasal dari Fredman dan Tarjan (1987).

### 5.2 Perbandingan dengan algoritma lain

| Aspek | Dijkstra | Bellman-Ford (23) | BFS (17) | Prim (21) |
| --- | --- | --- | --- | --- |
| Masalah | Lintasan terpendek berbobot | Lintasan terpendek berbobot | Lintasan dengan busur tersedikit | MST |
| Bobot negatif | Tidak boleh | Boleh; deteksi cycle negatif | Tanpa bobot | Boleh (tidak berpengaruh) |
| Struktur bantu | Antrean prioritas | - | Antrean FIFO | Antrean prioritas |
| Nilai yang diperbarui | $v.d = u.d + w(u, v)$ | $v.d = u.d + w(u, v)$ | $v.d = u.d + 1$ | $v.\mathit{key} = w(u, v)$ |
| Running time | $O((V + E) \lg V)$ | $\Theta(V E)$ | $O(V + E)$ | $O(E \lg V)$ |

*Tabel 6. Dijkstra dibandingkan dengan Bellman-Ford, BFS, dan Prim.*

- **Dijkstra sebagai perumuman BFS.** Jika semua bobot 1, Dijkstra mengeluarkan simpul berdasarkan jumlah busur, persis seperti BFS. Antrean FIFO cukup untuk BFS karena semua busur berbobot sama.
- **Dijkstra dan Prim.** Strukturnya hampir identik: keduanya meng-extract simpul dengan nilai minimum lalu memperbarui tetangga. Bedanya, Prim menyimpan bobot satu busur, Dijkstra menyimpan total bobot lintasan dari $s$.
- **Greedy yang terbukti.** Dijkstra adalah contoh algoritma Greedy (Modul 13) yang optimal dengan syarat tertentu, dan contoh penyangkal di atas menunjukkan pentingnya syarat itu.

@@ kesimpulan | KESIMPULAN | 6. Kesimpulan

- Dijkstra mencari lintasan terpendek dari satu sumber pada graf berbobot nonnegatif.
- Di setiap iterasi, simpul dengan $v.d$ terkecil di $Q$ di-extract, dimasukkan ke $S$ (jaraknya final), lalu semua busur keluarnya direlaksasi.
- Pada contoh bahan kuliah, urutan extract s, y, z, t, x menghasilkan $t = 8$ (s→y→t), $x = 9$ (s→y→t→x), $y = 5$ (s→y), $z = 7$ (s→y→z).
- Kebenarannya bergantung pada bobot nonnegatif; dengan bobot negatif hasilnya bisa salah, sehingga Bellman-Ford yang harus dipakai.
- Running time $O(V^2)$ dengan array, $O((V + E) \lg V)$ dengan binary heap, $O(V \lg V + E)$ dengan Fibonacci heap.
